# 15 — Working with Data

Real programs exchange data with the outside world: reading configuration,
saving structured records, processing a spreadsheet export, or working
with dates. This topic covers Python's standard-library tools for exactly
that.

**Prerequisite check:** `10-file-handling`, `08-dictionaries`, and ideally
`14-intermediate-python`'s comprehensions lesson.

## Lessons in This Topic

| # | Lesson | What You'll Learn |
|---|---|---|
| 1 | [Working with JSON](01-json.md) | Read/write the most common data-exchange format |
| 2 | [Working with CSV](02-csv.md) | Read/write spreadsheet-style tabular data |
| 3 | [datetime](03-datetime.md) | Represent, format, and calculate with dates and times |
| 4 | [pathlib](04-pathlib.md) | The modern, object-oriented way to work with file paths |
| 5 | [Basic Data Processing](05-basic-data-processing.md) | Combine everything above into a small pipeline |

Follow the table top to bottom -- lesson 5 deliberately combines the rest,
so save it for last.
