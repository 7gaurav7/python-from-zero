# 📚 Resources

Supplementary material to support your learning throughout the course.

- [`cheat-sheet.md`](cheat-sheet.md) — a single-page quick reference of
  Python syntax covered in this course.
- [`glossary.md`](glossary.md) — plain-language definitions of every term
  used across the lessons.
- [`further-reading.md`](further-reading.md) — where to go after finishing
  this repository, organized by interest area.
- [`pep8-quick-guide.md`](pep8-quick-guide.md) — the style rules this
  repository follows, summarized for beginners.
- [`debugging-tips.md`](debugging-tips.md) — how to read error messages and
  fix common bugs on your own.

Keep this folder open in a tab while working through the topics — the
cheat sheet and glossary are meant to be referenced constantly, not read
once.
